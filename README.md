# 장편 (jangpyeon-app)

이 폴더는 실제로 배포할 수 있는 홈페이지 코드예요. Supabase 접속 정보는 이미 채워져 있어서
별도로 뭘 입력하지 않아도 돼요.

## 배포하는 방법 (터미널 명령어 없이, 웹 화면만으로)

### 1단계 — GitHub에 올리기
1. github.com 에서 새 저장소(Repository)를 만드세요. (Public/Private 아무거나 상관없어요)
2. 저장소 페이지에서 "Add file" → "Upload files"를 클릭하세요.
3. 이 폴더(jangpyeon-app) **안의 파일과 폴더 전체**를 통째로 끌어다 놓으세요.
   (jangpyeon-app 폴더 자체가 아니라, 그 **안의 내용물**을 올려야 해요)
4. "Commit changes" 버튼을 눌러 업로드를 완료하세요.

### 2단계 — Vercel로 배포하기
1. vercel.com 에서 GitHub 계정으로 가입/로그인하세요.
2. "Add New..." → "Project"를 클릭하세요.
3. 방금 만든 GitHub 저장소를 선택하고 "Import"를 클릭하세요.
4. 다른 설정은 건드리지 말고 "Deploy" 버튼을 누르세요.
5. 1~2분 기다리면 실제 인터넷 주소(예: jangpyeon-app.vercel.app)가 생겨요!

이제 그 주소를 아무나 브라우저에 입력하면 우리 서비스에 접속할 수 있어요.

## 로그인은 어떻게 하나요?
비밀번호가 없어요. 이메일 주소만 입력하면 "매직 링크"가 담긴 메일이 오고,
그 링크를 누르면 자동으로 로그인돼요.

## 문제가 생기면
화면에 에러가 뜨거나 이상하게 보이면, 그 화면을 캡처해서 Claude에게 보여주세요.
